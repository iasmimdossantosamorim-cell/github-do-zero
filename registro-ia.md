# Registro de utilização da Inteligência Artificial

## Ferramenta utilizada

ChatGPT – Inteligência Artificial da OpenAI.

## Objetivo da utilização

A ferramenta foi utilizada como apoio para compreender os conceitos do GitHub, organizar as pesquisas e melhorar a clareza das explicações da cartilha.

## Prompt 1 – Pesquisa sobre GitHub

"Somos estudantes universitários iniciantes e precisamos criar uma cartilha sobre GitHub. Explique de maneira simples o que são Git, GitHub, repositório, README e Markdown, utilizando exemplos."

### Resultado da pesquisa

A IA apresentou explicações sobre os conceitos básicos do GitHub e exemplos para facilitar o entendimento.

## Prompt 2 – Colaboração no GitHub

"Explique de forma simples o que são commit, histórico de alterações, branch, Pull Request e Merge. Apresente exemplos práticos para estudantes iniciantes."

### Resultado da pesquisa

A IA auxiliou na compreensão das ferramentas utilizadas para registrar alterações e colaborar em projetos.

## Como verificamos as informações?

As explicações foram comparadas com a documentação oficial do GitHub e com as práticas realizadas pelo grupo na plataforma.

## Referência utilizada

https://docs.github.com/pt/

## Conclusão

A Inteligência Artificial foi utilizada como ferramenta de apoio à aprendizagem e organização do conteúdo. As informações foram conferidas para evitar erros e garantir que o material estivesse de acordo com a proposta da atividade.
