# DEV START – Aprendendo GitHub do Zero

## 1. Apresentação

Bem-vindo ao DEV START!

Esta cartilha foi criada para ensinar pessoas iniciantes a utilizar o GitHub de maneira simples e prática.

Nosso objetivo é apresentar as principais ferramentas da plataforma e mostrar como organizar projetos e trabalhar em equipe.

## 2. O que é Git e GitHub?

**Git:** é um sistema que controla as versões de um projeto e registra suas alterações.

**GitHub:** é uma plataforma online que permite armazenar projetos e colaborar com outras pessoas.

Exemplo: o Git registra as mudanças feitas em um projeto, enquanto o GitHub permite compartilhar esse projeto pela internet.

## 3. O que é um repositório?

Um repositório é um espaço onde ficam armazenados os arquivos de um projeto.

Existem dois tipos principais:

- Público: qualquer pessoa pode visualizar.
- Privado: somente pessoas autorizadas podem acessar.

## 4. O que é README?

O README é um arquivo utilizado para apresentar um projeto.

Ele pode conter:
- Nome do projeto.
- Objetivo.
- Integrantes.
- Instruções.
- Informações importantes.

## 5. O que é Markdown?

Markdown é uma linguagem simples utilizada para formatar textos no GitHub.

Exemplos:

# Título
## Subtítulo
**Texto em negrito**

- Primeiro item
- Segundo item

Com ele, podemos organizar informações de maneira simples e visual.

## 6. O que é Commit?

Commit é o registro de uma alteração realizada no projeto.

Exemplo: quando adicionamos uma imagem ou modificamos um texto, podemos registrar essa mudança com um commit.

Uma mensagem de commit deve explicar o que foi alterado.

Exemplo: "Adiciona imagem à página inicial".

## 7. O que é histórico de alterações?

É o registro das mudanças realizadas no repositório.

Ele permite identificar quem fez uma alteração e quando ela aconteceu.

## 8. O que é Branch?

Branch significa ramificação.

É uma versão separada do projeto utilizada para desenvolver melhorias sem alterar diretamente a versão principal.

## 9. O que é Pull Request?

Pull Request é uma solicitação para que uma alteração seja revisada antes de ser incorporada ao projeto principal.

Ele facilita a comunicação e a revisão entre os integrantes.

## 10. O que é Merge?

Merge é a ação de juntar as alterações de uma branch em outra.

Exemplo: depois que uma melhoria é revisada e aprovada, ela pode ser incorporada à branch principal.

## 11. Como compartilhar um repositório?

Para convidar uma pessoa:

1. Abra o repositório.
2. Acesse Settings (Configurações).
3. Procure Collaborators (Colaboradores).
4. Clique em Add people (Adicionar pessoas).
5. Digite o nome de usuário do colega.
6. Envie o convite.

A pessoa deverá aceitar o convite para acessar o repositório.

## 12. Cuidados ao compartilhar arquivos

- Não compartilhe senhas.
- Não publique tokens de acesso.
- Evite divulgar informações pessoais.
- Confira os arquivos antes de publicar.
- Escolha corretamente a visibilidade do repositório.

## 13. Desafio prático

Agora é sua vez!

1. Crie uma conta no GitHub.
2. Crie um repositório de estudos.
3. Escreva um README com seu objetivo.
4. Adicione três assuntos que deseja aprender.
5. Crie um arquivo de anotações.
6. Registre uma alteração com um commit.
7. Compartilhe o repositório com um colega.

### Como saber se concluiu?

Você deverá conseguir visualizar seu repositório, encontrar os arquivos criados e consultar o registro do commit.

## 14. Conclusão

Aprender GitHub é importante para quem deseja trabalhar com tecnologia e desenvolvimento de projetos.

A plataforma ajuda a organizar arquivos, acompanhar alterações e desenvolver atividades em equipe.

Com a prática, podemos conhecer melhor suas ferramentas e utilizá-las em projetos acadêmicos e profissionais.
