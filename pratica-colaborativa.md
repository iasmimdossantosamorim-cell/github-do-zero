# Nosso primeiro trabalho colaborativo no GitHub

## Objetivo

Esta atividade tem como objetivo demonstrar como diferentes pessoas podem colaborar em um mesmo projeto utilizando o GitHub.

## Como realizamos a atividade

1. Criamos um repositório compartilhado.
2. Convidamos os integrantes do grupo.
3. Criamos este arquivo para registrar nossas contribuições.
4. Cada integrante adicionou uma dica sobre GitHub.
5. Registramos as alterações utilizando commits.
6. Consultamos o histórico para identificar as contribuições.

## Dicas dos integrantes

### Integrante 1
O README apresenta as principais informações de um projeto.

### Integrante 2
Os repositórios permitem organizar arquivos e documentos.

### Integrante 3
Os commits registram as alterações realizadas.

### Integrante 4
As branches permitem desenvolver melhorias separadamente.

### Integrante 5
O Pull Request permite revisar alterações antes de incorporá-las.

## Registro dos testes

- Todos conseguiram acessar o repositório?
- Todos conseguiram editar o arquivo?
- As alterações apareceram para os demais integrantes?
- Conseguimos identificar os autores pelo histórico?
