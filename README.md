# PROJETO GITHUB - GUIA DE ESTUDOS E PRÁTICAS

Este repositório foi criado com o objetivo de documentar os conceitos fundamentais do Git e do GitHub, apresentando tanto a teoria de controle de versão quanto o fluxo de trabalho prático colaborativo utilizado em projetos de software.

# ESTRUTURA DO REPOSITÓRIO

O conteúdo deste projeto está organizado e dividido nos seguintes arquivos:

* **`cartilha.md`:** Apresenta os conceitos teóricos fundamentais sobre Git, GitHub, repositórios, visibilidade (público/privado), a função do arquivo README e a sintaxe de formatação Markdown[cite: 3].
* **`pratica-colaborativa.md`:** Detalha as etapas práticas do fluxo de trabalho em equipa, incluindo registo de alterações (commit), consulta de histórico, criação de ramificações (branch), solicitação de revisão (pull request) e integração de código (merge)[cite: 3].
* **`registro-ia.md`:** Documenta a utilização da Inteligência Artificial como ferramenta de suporte técnico para a estruturação dos ficheiros do projeto[cite: 2].
* **`imagens/`:** Pasta reservada para o armazenamento de esquemas visuais, diagramas e capturas de tela que auxiliam na explicação dos temas abordados.
