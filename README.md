# REPOSITÓRIO: O QUE É E PARA QUE SERVE?[cite: 1]

O que é um repositório?

Um repositório é um espaço digital dentro do GitHub utilizado para guardar, organizar e compartilhar arquivos de um projeto. Ele funciona como uma pasta, mas possui recursos especiais que permitem acompanhar todas as alterações realizadas nos arquivos. Dentro de um repositório podemos armazenar:
**Textos e documentos**.
**Imagens e vídeos**.
**Códigos de programação**.
**Arquivos de apresentação**.
**Informações e instruções sobre um projeto**.

Para que serve um repositório?

O repositório serve para organizar os arquivos de um projeto, registrar modificações, compartilhar informações e permitir que várias pessoas trabalhem juntas. Por exemplo, em um trabalho escolar, os integrantes podem utilizar um repositório para guardar a cartilha, as imagens, as pesquisas e os registros das atividades. Assim, todos conseguem acompanhar o desenvolvimento do trabalho.
